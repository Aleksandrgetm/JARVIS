# JARVIS — Core / Foundation

Локальный текстовый CLI-ассистент для macOS. Версия 0.1.0, только этап 1.
Требуется Python 3.9 или новее. Сторонних зависимостей нет, pip install не нужен.

## Запуск

В каталоге проекта:

```bash
python3 main.py
```

```text
JARVIS
System online.

jarvis > status
JARVIS is online.
jarvis > version
JARVIS 0.1.0
jarvis > exit
System offline.
```

## Команды

| Команда | Назначение |
| --- | --- |
| help | Список команд из реестра Router |
| status | Состояние ассистента |
| version | Версия приложения |
| clear | Очистка терминала ANSI-последовательностью |
| exit | Корректное завершение |

Регистр не важен, пробелы по краям игнорируются. Аргументы пока не поддерживаются.
Пустой ввод пропускается. Неизвестная команда показывает подсказку.
Ctrl+C и EOF (Ctrl+D) завершают приложение. Ошибка обработчика записывается
в лог, CLI продолжает работу. При перенаправлении stdout команда clear ничего
не выводит. Shell-команды не запускаются.

## Архитектура

- `main.py`: сборка конфигурации, логирования и запуск Assistant.
- `core/assistant.py`: цикл CLI, ввод/вывод и обработка ошибок; зависимости
  ввода/вывода можно заменить в тестах или другом интерфейсе.
- `core/router.py`: реестр Command, поиск обработчика, проверка разрешений.
  Обработчик возвращает CommandResult (сообщение и флаги выхода/очистки).
  Router не зависит от терминала; ошибки перехватываются на границе CLI.
- `core/commands.py`: регистрация пяти встроенных команд.
- `core/permissions.py`: SAFE разрешён; CONFIRM требует явного
  `confirmed=True`; DANGEROUS заблокирован. Это внутренняя политика, а не
  система разрешений macOS. Диалог подтверждения пока не реализован,
  все встроенные команды имеют уровень SAFE.
- `core/config.py`: неизменяемые настройки и путь данных относительно проекта.
- `core/logger.py`: UTF-8 журнал `data/logs/jarvis.log`, ротация при
  1 000 000 байт, до трёх архивных файлов; traceback ошибок обработчиков.
- `actions/`, `brain/`, `voice/`, `memory/`: пустые пакеты для будущих этапов.

Логи создаются автоматически и исключены из Git. При старте каталог логов
должен быть доступен для записи. Неизвестный пользовательский ввод не сохраняется.

## Проверка

```bash
python3 -m unittest discover -s tests -v
```

Тесты используют стандартный unittest и не требуют внешних сервисов.

## Границы этапа

Управление macOS, STT/TTS, AI/LLM, Codex, SQLite, SwiftUI/GUI и wake word
не подключены. OpenAI API, Whisper, AppleScript и выполнение shell-команд
отсутствуют. Дальнейшая разработка выполняется отдельными этапами.
